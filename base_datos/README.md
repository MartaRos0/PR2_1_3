# Contenido de la carpeta
## Sistema de Gestión de Producción y Base de Datos

Proyecto desarrollado en **Python** _(Base_datos)_ y **PostgreSQL** _(DDL_proyecto.db)_ para la gestión automatizada de una línea de producción mediante integración con **RoboDK**.

El sistema permite controlar el stock, registrar cajas fabricadas, gestionar pedidos y monitorizar la producción en tiempo real.
