# Web PR2 — Modelos LEGA

## Descripción
Esta web forma parte del proyecto PR2 y permite visualizar y seleccionar diferentes modelos **LEGA** creados para la práctica.  
El usuario puede explorar los modelos disponibles y elegir uno para continuar con el pedido.

## Contenido de la web
- **Página principal:** muestra los modelos disponibles.  
- **Botones verticales:** permiten cambiar entre modelos.  
- **Vista de pedido:** selección de cantidad y confirmación.  
- **Diseño responsive:** adaptado a móvil y ordenador.

## Tecnologías utilizadas
- **HTML5**  
- **CSS3 (Flexbox, responsive design)**  
- **JavaScript básico**
